# 选择性必修1第一章《地球的运动》对照盘点

核查范围：工作区教材 PDF 第6—21页；对照对象为项目 v0.21.1 的实验室、诊断题与复测闭环。

## 对照结论

项目原有内容已较完整覆盖自转与公转方向、角速度和线速度、地方时与日期、晨昏线、黄赤交角、太阳直射点、昼夜长短、正午太阳高度、四季与五带。完整缺口是地转偏向力；其余缺口适合用紧凑诊断题补齐，不必各建一个实验室。

| 教材知识点 | 原项目覆盖 | v0.21.0处理 |
| --- | --- | --- |
| 地转偏向力：北右南左、赤道不偏、只改方向、大尺度气流和水流 | 缺失 | 新增 `coriolis-lab`，8个南北半球/赤道与运动方向情境 |
| 太阳日与恒星日 | 仅有24小时自转模型 | `GEO-EARTH-001` |
| 回归年与恒星年 | 仅有周年回归过程 | `GEO-EARTH-002` |
| 北极星高度、星轨与纬度 | 缺少直接诊断 | `GEO-EARTH-003` |
| 黄道面、赤道面与黄赤交角定义 | 有交角应用，定义辨析较弱 | `GEO-EARTH-004` |
| 北极上空看自转、公转方向 | 自转已覆盖，公转同向辨析较弱 | `GEO-EARTH-005` |
| 实际国际日界线的弯折 | 原实验采用180°理想模型 | `GEO-EARTH-006`，保留理想模型并补现实边界 |
| 天文四季与气象四季 | 有四季成因，划分口径不足 | `GEO-EARTH-007` |
| 二十四节气的黄道位置含义 | 有二分二至与周年曲线，未单独辨析 | `GEO-EARTH-008` |

## 暂不单独建实验的内容

- 昼夜现象与昼夜交替的区别：可在晨昏线、极昼极夜复盘中追问；
- 月球同步自转与“人工月亮”探究：属于拓展探究，待真实错因出现后再决定是否立项；
- 季节与太阳直射点迁移的绘图表达：现有周年回归、太阳季节和太阳视运动三类实验已提供足够模型，可优先用真实题检验迁移。
