# 选择性必修2：橙子14天复习

## 使用方式

从“项目”进入“区域发展·14天复习”。每天先按页面标注的教材页码阅读并完成两条证据提取，再做当天2道资料包诊断题。提交前不显示答案；提交后保留原题四个选项，并可“保存并继续下一题”或返回目录当前位置。

教材PDF和完整资料包只保留在家庭工作区，不随GitHub Pages发布。网页只发布实际入题所需的精选图表；所有题图可点按查看原尺寸，表格在窄屏上可横向滚动。

## 资料完整性与来源

- 62道已部署诊断题和2组复测全部来自资料包，不再加载原创诊断题或原创复测题。
- 每道题记录资料包课时与题号；涉及地图、统计图或表格时同时保留图例、单位和共用材料。
- `assets/questions/` 只存实际入题所需的精选题图；`教材/`、完整资料包和 `local_learning_sources/` 保持Git忽略。
- 每个 `knowledge_point_id` 安排2—5道题；14天区域复习固定每天2道，共28道。

## 学生、家长与数据

- 学生作答前看不到答案、解析或复测评分点；作答记录保存到浏览器LocalStorage。
- 系统只给出候选错因。家长核对图、表、文字证据后再确认、修正或标记教师复核。
- “已作答”不等于“已掌握”；只有间隔后的资料包复测与学生解释通过，才能更新掌握判断。

## 验证

运行 `npm test`，检查62道诊断题均来自资料包、14天与28道题一一对应、每个知识点2—5题、2组复测题源、所有发布题图路径、表格行列、教材目录唯一归属、提交前隐藏答案、讲解页保留选项，以及目录折叠和当前题定位标记。
