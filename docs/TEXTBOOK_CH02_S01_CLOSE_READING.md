# 第二章第一节逐页精读说明

## 范围

- 教材：人教版《地理·选择性必修1·自然地理基础》
- 章节：第二章第一节“塑造地表形态的力量”
- 教材页：18—25页，对应PDF第23—30页
- 发布边界：本版本只完成第一节，第二节未开放

## 橙子的使用路径

1. 从“学习—正在学习”进入第一节逐页精读。
2. 先读当前教材页，填写3—6个关键词、一条因果链和一个真实疑问。
3. 保存后核对逐页解析、知识发散和高考迁移，再进入下一页。
4. 完成8页后做2道浙江选考真题和2道资料包例题；提交前不显示答案与完整解析。

阅读证据保存在浏览器 LocalStorage。页面是否“已读”只表示留下了阅读记录，不表示已经掌握。

## 家长介入

家长任选2页，让橙子脱离解析按“证据—过程—结果”复述。若答题正确但理由不能对应材料，仍保留为“需要更多证据”；至少间隔48小时后再用换图题复测。

## 来源与发布

- 教材内容来自项目内人教版选择性必修1教材PDF，只发布本节8张教材页面图片，不发布整本PDF。
- 高考真题为2021年1月浙江选考第3—4题，题面、选项、答案与原解析按资料包核对。
- 资料包例题来自步步高一轮复习“课时25 塑造地表形态的力量”考向1第1—2题。
- 逐题核对字段记录在 `data/question_source_fidelity.json`，发布校验会检查题目关系与图像存在性。
