# “宇宙中的地球及运动”实验路线

## 执行规则

- 每个版本只新增一个实验；
- 每个实验都必须包含学生预测、文字判断链、候选错因、家长审核和至少48小时后的换情境复测；
- 发布前完成内容校验、脚本检查、iPad横竖屏、手机和线上页面验收；
- 发布后根据已覆盖知识链与橙子的真实记录重新排序，不机械追求数量。

## 已完成

1. 时区与地方时实验室：经度、地方时、区时和日期；
2. 晨昏线与观察视角实验室：视角、自转方向、昼夜变化和晨昏线；
3. 太阳直射点与昼夜长短实验室：二分二至、昼长和正午太阳高度；
4. 日出日落与太阳视运动实验室：地平圈方位、天空轨迹和影子；
5. 太阳直射点周年回归实验室：四个节气之间的直射纬度、移动方向和趋势。
6. 地球公转轨道与速度实验室：近日点、远日点、公转快慢、半球季节和四季成因。

## 后续优先清单

1. 晨昏线综合联动：直射经线、地方时、极昼范围和昼长；
2. 地球自转速度：角速度、线速度与纬度关系；
3. 全球日期范围：0时经线、180°经线和新旧日期占比；
4. 黄赤交角变化：直射范围、极昼范围和五带变化；
5. 天体系统尺度与地球宇宙位置；
6. 地球宜居条件的可检验比较；
7. 太阳辐射与太阳活动影响。

月相、日月食和潮汐先标记为“视教材与学校进度决定”，不在核心链未完成前抢占优先级。
