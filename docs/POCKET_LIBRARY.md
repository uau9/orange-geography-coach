# 口袋书逐专题扩展与发布

按用户确认的方式，每次只完成一个专题；该专题提取、校验、发布并确认线上可用后，再进入下一专题。

## 使用

进入“背诵”→“口袋书 · 知识清单”，在“选择专题”中切换。目录中只显示已完成的专题，按原专题编号排列。正文仍按知识清单、易错易混、知能拓展的原顺序编排；思维导图在专题总览中默认折叠。

普通文字和表格内空格默认隐藏，点击只显示本空，再次点击隐藏。完整标注的原图先折叠，口头回忆后展开核对，可放大查看。人口专题继续保留已确认的12处图内答案遮盖。查看提示只记录提示次数，不自动计为掌握；家长需听完脱离答案的复述，再标记，并在后续安排延迟复测。

新增专题使用独立数据文件，选中时才加载；人口单元编号、基础挖空单元编号和本机 `recallProgress` 保持兼容，专题选择及学习记录保存在本机，不上传。切换专题和刷新会重新隐藏答案。

## 数据与来源

- `data/pocket_library.json`：已完成专题目录，版本1.0.0。
- `data/pocket/`：新增专题数据，版本1.1.0，结构见 `schemas/pocket-book.v1.1.schema.json`。1.1.0在原样板基础上新增公式结构、可折叠原图、多个总览图及表格行定位。
- `data/pocket_population.json`：已发布人口样板，保持原1.0.0结构和单元编号。
- `scripts/pocket-book-profiles.json`：逐专题核对的源块范围、非教学装饰排除、编辑修订及依据。每条修订必须在原文命中，未命中时生成失败。
- 每个段落保留原文、源块及表格行编号；每个源文件、网页图像保存SHA-256。表格保留跨行跨列合并；分式与指数按MathML表达，红色公式答案同样默认隐藏。
- 原DOCX保持本机只读，不随网站上传。网站仅包含所需教学原图、对应文字与审校记录。

## 验证

`npm test` 同时检查人口样板与已完成专题：源文到展示文字的对应、修订记录、单元顺序、空格唯一编号与独立隐藏、公式树、表格网格完整性、原图哈希。浏览器按专题验证手机与桌面选择、全部空格显隐、原图展开/放大、刷新后恢复选择及答案重隐藏、人口旧记录兼容；部署后验证线上版本和专题。
