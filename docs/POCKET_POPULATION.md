# 口袋书专题11人口背诵样板

## 范围与使用

人口样板以《2024年高考地理一轮复习知识清单》专题11人口DOCX为唯一编排来源。进入底部“背诵”→“口袋书 · 知识清单”，选择“专题11 人口”，按原文顺序选择单元。2026年11月1日，用户完成本地测试并确认发布到现有网页端；本版提供人口专题样板。

保留三个知识清单、两个易错点和三个拓展考点。原文训练营与答案解析不混入背诵正文，避免学生未作答先看到答案；考情与装饰素材不放入卡片。

纳入原文件第2页的思维导图，放在目录前的“专题总览”中，默认折叠。先回忆人口分布、迁移和容量的结构，再展开原图核对；可放大横向查看。原图不作逐空遮盖，不计入131个背诵空格。图中旧表述、文字错误的辨析放在原图下方，正文修订仍作为具体概念依据。

| 组别 | 单元 |
| --- | --- |
| 知识清单 | 人口分布和人口变化、人口容量、人口迁移 |
| 易错易混 | 常住人口和户籍人口、我国的人口问题及对策 |
| 知能拓展 | 影响人口迁移因素的分析方法、人口模式图判读、人口惯性与计生政策的变化 |

## 背诵与家长确认

- 先口头完成句子，再点淡橙色空格，仅显示本空答案；再次点击隐藏。切换单元或刷新默认隐藏。
- 文字答案在原句中展开，不使用悬浮框。长答案允许正常换行，表格可横向滑动，避免为塞进小格而无限缩小字号。
- 8张图（1张总览图、7张教学图）保持原始像素和宽高比。12个重要图内答案使用单独的橙色遮盖；“放大图示”支持横向查看和逐空点击。放大视图重新隐藏答案，不修改原图。
- 手机点击目录直接进入正文，正文上方可返回目录；桌面保持并排布局。
- 家长听完不看答案的复述后，可标记“家长已听口头复述”；仍需延迟复测，不直接计为掌握。错漏时标记“还没记牢”，下次脱离答案重述。
- 提示次数、提示时间和家长标记复用本机 `recallProgress`，单元编号 `pocket11-01` 至 `pocket11-08`；旧版学习记录无需迁移。显隐状态不保存，数据不上传。

## 提取与保真

- 源文件只读；数据位于 `data/pocket_population.json`，结构版本为 `1.0.0`，schema为 `schemas/pocket-recall.v1.schema.json`。
- 保留正文块顺序、每个段落原文 `source_text`、源正文块编号 `source_block`、每个单元的源范围及原DOCX SHA-256。
- 按红色下划线识别原答案，合并同一答案的相邻Word片段；额外挖空标记为 `reviewed-addition`，图内遮盖标记为 `reviewed-image-mask`。
- 共131空：84个来自原标记，35个经审阅补充，12个为图内遮盖；其中68个在表格中。与初评87个源标记的差异，来自修订句替换后的重新挖空。
- 14张表保留网格、跨列与跨行合并。8个原图逐字节提取，保存SHA-256。标题的AlternateContent只保留一个分支，避免重复。
- 不采用整页截图。此前抽样转换存在字体缺失和分页变化，结构化网页可使用设备中文字体并适应手机宽度。

## 核查与修订

13条编辑修订逐项存入 `audit.corrections`，含原文、修订文、理由和外部参考编号。重点包括：

1. 区分总人口性别比与出生人口性别比，明确以女性为100。
2. 将“我国人口增长速度较快”更新为有明确年份的判断：2025年自然增长率为−2.41‰，不把旧资料背景当作当前事实。
3. 按我国统计口径修正常住人口说明，对常住人口简式添加地域、时点、分类一致且不重复的前提。
4. 明确限制性资源是相对于人口需求的短板；容量比较须在相同条件下。
5. 补充人口迁移的时间、空间条件，区分短期旅行和通勤。
6. 区分年龄结构类型与人口增长模式，不能只凭成年型金字塔就认定增长模式。
7. 对性别比失衡的对策、文字错误以及人口政策的绝对化表述作局部修订。

对于不同发展阶段国家、人口增长模式国家举例、历史迁移格局和年轻化/老龄化的概括，保留原表并加辨析提示；具体题目以材料年份与指标为准。图中生育更替水平约2.1是概括性示例，不能当作所有国家和时期的固定值。

本次为样板编辑核查与重点概念查证，外部参考不代表逐字认证整份资料。内容取舍、挖空粒度、表格和图片效果已通过用户本地试用确认；后续扩展应沿用本样板的逐项来源与校验记录。
