# 挖空背诵卡

## 内容边界

- 来源：《高中地理基础知识挖空复习（含答案）》26版。
- 编排：严格依原PDF第1-74页和原章节、课时顺序，共5章、25课时。
- 保真：题面以原页图像呈现，不重排表格和示意图；答案页的题面续页与答案区按PDF坐标切分。
- 发布资产：`assets/recall/geography-basics-26/` 仅包含网页所需的逐页JPG，原PDF仍保持在Git忽略的本机资料目录中。

## 学生如何使用

1. 从底部“背诵”进入，目录按原章节展开。
2. 先口头完成原页挖空，不会时点击与原行对齐的淡橙色矩形。
3. 只在原淡橙色矩形内显示该空格的独立答案，不另弹出边框或浮层，不遮挡上下行；文字按空格大小自动缩放，长答案可换行。其他未点击的空格继续隐藏。表格、整块空白答案格和图内挖空使用相同交互。较长答案在手机缩略页中可能较小，可使用“放大背诵”。
4. 再次点击同一空格隐藏答案，然后脱离答案重述。切换课时、刷新或进入放大视图时默认隐藏。
5. 手机字小时点“放大背诵”，可横向移动查看完整表格与图示，放大后仍可逐空点击；放大页不会打开原答案区。

## 家长如何介入

- “还没记牢”只记录需再背；“家长已听口头复述”由家长在学生不看答案的情况下点击。
- 口头复述也不直接算稳定掌握；应在后续课时或延迟复测中再验证。
- 答案显示次数、最近显示时间和家长标记保存在浏览器 `localStorage`，不上传服务器。

## 遗漏与正确性核查

- 补全了原文整课缺失的“地球自转和公转（第二课时）”答案。
- 补全了地下水补给、洋流概念和自然环境整体功能作用等缺项。
- 纠正了“东非高原-热带沙漠气候”、“极低高气压带”等明显错误，并对ENSO影响加上“统计倾向、非必然”的边界。
- 补全锋面/锋线、四个气压带形成原因、湖泊和地下水补给影响因素，以及图中的二分二至日期、海陆气压中心与河湖补给关系。
- 第57页洋流示意图上方20℃、下方18℃，应判断为南半球；洋流从低温海区流向高温海区，是寒流。图旁的三个相关空格为“南、凸、寒”。冰原气候表中“太阳辐射”空为“弱”。
- 答案依据保存在生成脚本的逐空清单与数据的 `audit.references`。重点联网核查参考 [USGS 河流与地下水交换](https://www.usgs.gov/water-science-school/science/rivers-contain-groundwater)、[NOAA 洋流](https://oceanservice.noaa.gov/facts/current.html)、[国家气候中心 ENSO 影响](https://www.ncc-cma.net/channel/news/newsid/4685)。这些来源用于核查对应概念，不代表逐字认证整份讲义。
- 结构校验检查74张原页图像、页码连续性、每空非空答案/唯一编号/坐标边界、表格空格覆盖和关键纠错。浏览器验证逐空显隐、表格、放大视图与手机布局。

## v0.29.1 数据与交互修正

- 目录数据由1.0.0升级为1.1.0，每个空格增加 `id`、`answer`、`kind`。`kind` 区分正文、表格和图内挖空。
- 共881个独立空格。自动识别兼容0.48点的细线，剔除表格边框；同一单元格内的断裂下划线合并，不跨单元格合并。表格按单元格阅读顺序绑定答案。
