# 产品简报 v0.2

## 一句话定位

一个让家长看见“橙子为什么错、AI依据是什么、是否真的改会了”的地理学习闭环。

## 三个角色

### 橙子

- 先独立作答；
- 必须写选择理由，而不是只点选项；
- 给出信心等级；
- 根据追问重新解释；
- 接受延迟复测。

### AI

- 把题目、答案、作答理由整理成诊断候选；
- 区分知识错误、概念混淆、读图/审题错误、推理链断裂和粗心；
- 提出 1–2 个追问和一个最小补救任务；
- 不替代家长确认，不把一次表现升级为稳定结论。

### 家长

- 看证据，不靠“今天学了吗”判断；
- 确认或修正 AI 的诊断；
- 观察情绪和执行状态；
- 连续停滞时决定是否引入学校老师或专业家教；
- 不在每道题上直接讲答案。

## 首版不做什么

- 不做六科大而全；
- 不做排行榜、连续打卡惩罚和复杂游戏化；
- 不接入未验证的题库抓取；
- 不把 AI 聊天记录等同于学习效果；
- 不在浏览器前端保存任何 API 密钥。

## 成功指标

首周只看四件事：

1. 橙子是否愿意每天完成一题；
2. 是否真的写理由；
3. 家长是否能在 3 分钟内完成审核；
4. 48–72 小时后的同类题是否比第一次更稳定。

## 真实试卷复盘

- 原始卷面分与标准分必须使用不同字段保存，不直接换算或混合比较；
- 只记录小问得分、学生答案证据摘要、评分点和候选错因；
- 不把姓名、学号、班级、座位号或原始答题卡图片写入 Git 仓库；
- 复测必须换情境，且在学生提交前不显示答案或评分点；
- 家长按评分点确认“已掌握 / 需再练 / 需教师复核”。
