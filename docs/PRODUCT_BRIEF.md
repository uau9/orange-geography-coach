# 产品简报 v0.13

## 一句话定位

一个让家长看见“橙子为什么错、AI依据是什么、是否真的改会了”的地理学习闭环。

## 三个角色

### 橙子

- 先独立作答；
- 必须写选择理由，而不是只点选项；
- 给出信心等级；
- 根据追问重新解释；
- 接受延迟复测。

### AI

- 把题目、答案、作答理由整理成诊断候选；
- 区分知识错误、概念混淆、读图/审题错误、推理链断裂和粗心；
- 提出 1–2 个追问和一个最小补救任务；
- 不替代家长确认，不把一次表现升级为稳定结论。

### 家长

- 看证据，不靠“今天学了吗”判断；
- 确认或修正 AI 的诊断；
- 观察情绪和执行状态；
- 连续停滞时决定是否引入学校老师或专业家教；
- 不在每道题上直接讲答案。

## 首版不做什么

- 不做六科大而全；
- 不做排行榜、连续打卡惩罚和复杂游戏化；
- 不接入未验证的题库抓取；
- 不把 AI 聊天记录等同于学习效果；
- 不在浏览器前端保存任何 API 密钥。

## 成功指标

首周只看四件事：

1. 橙子是否愿意每天完成一题；
2. 是否真的写理由；
3. 家长是否能在 3 分钟内完成审核；
4. 48–72 小时后的同类题是否比第一次更稳定。

## 长期项目的信息结构

- “今日”只回答下一步，不承担专题目录功能；
- “项目”统一列出互动实验、诊断题和延迟复测，并展示各自最近证据；
- “掌握”只呈现跨时间验证，不用一次表现替代掌握结论；
- “家长”集中审核原始证据、外部教练批注与数据迁移；
- 新专题必须先登记项目清单，再提供独立数据、schema、功能入口和验证规则。

## 可批注学习档案

- 文件名和档案正文均记录精确导出时间，正文同时记录UTC、本地时间和时区；
- 摘要只用于帮助定位证据，不能替代原始作答、理由和家长确认；
- AI或教师不得修改原始记录，只能向 `coach_annotations` 追加结构化批注；
- 每条批注必须引用 `evidence_refs`，并标明“候选 / 已确认 / 需教师复核”；
- 导回浏览器后保留既有批注，便于按时间持续跟踪。

## 时区专项成功标准

- 经度先通过平面世界地图、城市或地区建立空间参照，再用滑杆精确到整数度；
- 地图选点、地点按钮和经度滑杆必须同步，不能让图示与实际计算经度不一致；
- 学生提交前看不到地方时、理论区时和日期答案；
- 每次实验必须留下方向、两个钟点、日期判断和文字理由；
- 错因定位到具体步骤，不笼统记录为“时区不会”；
- 家长能在3分钟内判断候选错因是否有证据；
- 延迟复测必须换UTC时刻或经度，不能只重复原数字。

## 晨昏线专项成功标准

- 学生必须先确定观察视角，再判断自转方向，不能跳步背结论；
- 提交前不显示自转箭头、昼夜标签和晨昏线名称；
- 错因分别定位到受光半球、观察视角、自转方向、昼夜变化和界线命名；
- 家长审核学生的文字判断链，AI和系统结论只作为候选；
- 至少48小时后换视角或换交点再次满分并由家长确认，才能显示延迟复测通过；
- iPad横竖屏必须能完成全部触控操作，文字和图形不依赖悬停。

## 太阳直射点与昼夜长短专项成功标准

- 学生必须先由日期确定太阳直射点，再判断昼长，不能直接背“北半球夏季昼长”；
- 提交前不显示直射纬线、约昼长和正午太阳高度答案；
- 具体地点与纬度同时出现，城市经验不能替代纬度判断；
- 极昼极夜、一般昼长和全球纬度规律使用不同错因标签；
- 正午太阳高度只使用高中地理公式，约昼长仅用于图形理解，不要求球面三角计算；
- 至少48小时后换二分二至日情境再次满分并由家长确认，才能显示延迟复测通过。

## 日出日落与太阳视运动专项成功标准

- 提交前天空罗盘不显示太阳轨迹、日出日落方位、正午太阳和影子答案；
- 日出日落与正午太阳必须作为两条不同判断链，不能用“北半球夏季”一句话代替；
- 太阳轨迹通过日期和地点计算，影子方向必须与当前太阳水平方位同步相反；
- iPad上可直接拖动一天时间轴，所有关键操作不依赖鼠标悬停；
- 系统只生成具体步骤的候选错因，家长仍需根据橙子的文字理由确认；
- 至少48小时后换日期再次满分并由家长确认，才能显示延迟复测通过。

## 太阳直射点周年回归专项成功标准

- 学生提交前只能看见日期在周年轴上的位置，不能看见回归曲线、直射纬度和移动方向；
- 直射点位置与移动方向分别作答，系统不能把二者合并成一个笼统结论；
- 二至日按方向转折点判断，5月与8月等同纬度情境必须能区分相反方向；
- 北半球昼长趋势与北京/悉尼正午太阳高度趋势分别留下证据；
- 提交后可拖动周年位置观察连续变化，iPad触控不依赖悬停；
- 至少48小时后换到相反移动方向再次满分并由家长确认，才能显示延迟复测通过。

## 地球公转轨道与速度专项成功标准

- 学生提交前只能看到轨道、太阳焦点、公转方向和所选日期位置，不能看到距离数值、速度箭头与30天轨迹；
- 日地距离状态与公转速度必须分别作答，不能只背“近快远慢”而无法定位1月、7月；
- 南北半球季节必须可在同一轨道位置切换比较，用共同距离、相反季节反证距离成因；
- 四季主要成因必须明确到“地轴倾斜且公转时指向近似不变”，系统只把错误判断记为候选；
- 示意图中夸大的椭圆度、速度箭头和轨迹差异必须在作答前后持续标注，真实近似数值保留来源；
- 至少48小时后在近日点与远日点、不同半球情境中再次满分并由家长确认，才能显示延迟复测通过。

## 晨昏线综合联动专项成功标准

- 学生提交前只能看到日期、UTC、目标地点和无答案底图，不能看到昼夜范围、晨昏线或直射经线；
- 直射经线、地方时、昼长、当前晨昏状态和极昼极夜范围必须分别作答并保留文字判断链；
- 地方时采用高中地理理想模型，明确与法定区时分开；昼长用于推导日出日落，不把所有晨昏线点机械写成6:00/18:00；
- 提交后可拖动UTC时刻，全球昼夜范围、两条晨昏线、直射经线和目标地点状态必须同步更新；
- 五类错误分别生成候选标签，只有家长可确认或标记教师复核；
- 至少48小时后更换日期，并在晨昏线与昼夜区两种状态类型之间换情境满分，才能显示延迟复测通过。

## 地球自转速度专项成功标准

- 学生提交前只能看到目标纬度、观察时长和纬线圈，不显示速度箭头、数值和运动弧长；
- 角速度、线速度关系、线速度数值、时段转角和时段路程必须分别作答；
- 使用24小时转360°与赤道线速度约1670 km/h的高中理想模型，明确不计地球扁率；
- 提交后可拖动24小时，目标点、运动弧线、速度方向、转角与路程读数同步更新；
- “角速度随纬度变化”和“线速度随纬度变化”必须使用不同候选错因，家长仍需按判断链确认；
- 至少48小时后跨低纬、高纬并更换观察时长再次满分，才能显示延迟复测通过。

## 全球日期范围专项成功标准

- 学生提交前只能看到UTC时刻、跨线方向和无答案世界底图，不能看到0时经线或日期带；
- 0时经线、较新日期占比、较旧日期占比、日期数量和跨线结果必须分别作答并保留文字判断链；
- 采用高中理想模型，把180°经线视为国际日界线，并明确说明实际日界线存在弯折；
- 提交后可拖动UTC一天，0时经线、两侧日期带、百分比和日期数量必须同步更新；
- “0°经线”和“0时经线”混淆、日期范围方向、占比互补与跨线方向必须使用不同候选错因；
- 至少48小时后在“全球同属一个日期”与“全球存在两个日期”两类情境中再次满分并由家长确认，才能显示延迟复测通过。

## 真实试卷复盘

- 原始卷面分与标准分必须使用不同字段保存，不直接换算或混合比较；
- 只记录小问得分、学生答案证据摘要、评分点和候选错因；
- 不把姓名、学号、班级、座位号或原始答题卡图片写入 Git 仓库；
- 复测必须换情境，且在学生提交前不显示答案或评分点；
- 家长按评分点确认“已掌握 / 需再练 / 需教师复核”。
