# 橙子地理教练

面向高三地理学习的“AI + 家长”诊断型学习项目。它不是一个单纯的题库，也不是把 ChatGPT 塞进网页，而是记录一条可复盘的学习证据链：

**作答 → 写理由 → AI 诊断候选 → 家长确认 → 同类复测 → 更新掌握状态**

## 当前版本：v0.5.1

首版刻意不接在线 API，避免在学习方法尚未验证前把项目做成昂贵的聊天框。AI 通过复制结构化提示词到 ChatGPT 完成，结果再粘贴回项目；家长是最终审核者。

已包含：

- 今日任务与学习概况；
- 单题诊断流程；
- 学生作答理由、信心等级和错因候选；
- AI 诊断提示词复制、结果粘贴；
- 家长审核、备注和“需要再看”标记；
- 主题掌握统计；
- 本地保存、JSON 导入/导出；
- 3 道原创示例题，覆盖自然地理、人文地理和区域认知。

v0.3 新增“时区与地方时”专项：

- 手机端时区实验室：选择经度后，先预测地方时、理论区时和日期，再解锁联动结果；
- 8 道原创诊断题，覆盖UTC、地方时、区时、航班计算、国际日界线和全球日期；
- 固定的时区错因标签，区分概念、经度换算、方向、时区、日期和计算顺序；
- 家长可审核每次实验的判断链和候选错因；
- 一组换时刻、换经度的开放式延迟复测，提交前不显示评分点。

v0.3.2 将手机端时间答案拆为“小时：分钟”两个数字输入框，冒号由界面固定显示，不再要求学生从数字键盘输入符号。

v0.4.0 将经度滑杆升级为交互式平面世界地图：城市与地区提供空间参照，点击地图仍可精确选择任意整数经度，地图、地点按钮和滑杆会同步更新。

v0.5.0 新增“晨昏线与观察视角实验室”：

- 在北极上空、南极上空和赤道侧视之间切换，先预测再解锁运动箭头；
- 分步判断受光半球、自转方向、进入白昼/黑夜和晨线/昏线；
- 记录固定 `error_tag`、学生判断链和家长审核结论；
- 只有两次家长确认的满分记录间隔达到48小时，掌握页才显示延迟复测通过；
- iPad横竖屏使用双栏布局，手机自动切换为上下布局。

v0.5.1 修正极点俯视图的自转箭头：北极上空按逆时针绘制，南极上空按顺时针绘制。

v0.2 新增：

## 本地运行

在项目目录执行：

```bash
npm test
npm start
```

然后打开 <http://localhost:4173>。

也可以直接执行：

```bash
python3 -m http.server 4173
```

## 在线访问

固定网址：<https://uau9.github.io/orange-geography-coach/>

在 iPad 或 iPhone 上使用 Safari 打开后，可以点击“分享”→“添加到主屏幕”，以后从桌面图标进入。网页和匿名题目通过 GitHub Pages 发布；学生作答、家长审核和掌握记录仍保存在当前浏览器的 LocalStorage 中，不会上传到 GitHub，也不会自动同步到其他设备。

如果学生和家长使用不同设备，当前版本需要通过“导出学习记录”和“导入学习记录”交接；不要发送含个人身份信息的导出文件。

## 一次真实使用建议

第一周不要追求每天做很多题。每天 15–25 分钟：

1. 橙子完成 1 道题，并写出为什么这样选；
2. 将诊断提示词交给 AI；
3. 家长只检查“理由是否真实、AI 诊断是否有证据、下一步是否明确”；
4. 48–72 小时后再做同类变式题；
5. 周末复盘：哪些错误是知识不会，哪些是读图/审题/推理链断裂。

### 时区专项的一次使用

1. 进入“时区实验室”，先在世界地图上选择城市或地点，必要时再用滑杆微调经度；
2. 在看结果前，写出东西位置、地方时、理论区时、日期和判断链；
3. 提交后只核对错误发生在哪一步，不把一次满分直接写成掌握；
4. 完成8道诊断题，家长确认高频 `error_tag`；
5. 48—72小时后完成“同一瞬间的三种时间”复测。

### 晨昏线专项的一次使用

1. 选择北极、南极或赤道观察视角；
2. 提交前依次判断受光半球、自转方向、昼夜变化和晨昏线名称；
3. 解锁图中运动箭头后，对照自己的文字判断链；
4. 家长确认候选错因是否能被作答证据支持；
5. 至少48小时后换观察视角和交点复测，不能用一次满分宣布掌握。

## 当前边界

- 数据保存在当前浏览器的 LocalStorage，不具备多设备同步；
- AI 结果仍需复制粘贴，便于先验证流程，也避免把密钥放入前端；
- 示例题不是完整高考地理课程，正式内容必须经过家长或教师审核；
- 不能依据一次答错就断言橙子“掌握不足”，系统只记录候选诊断。
- 真实试卷图片与个人信息不写入仓库；录入数据只保留匿名分数、评分点摘要和诊断证据。

## 下一阶段

优先顺序应是：真实使用晨昏线与时区专项 7 天 → 检查高频 `error_tag` 是否准确 → 增加昼夜长短与正午太阳高度实验 → 增加广东新高考地理变式。
