# 橙子地理教练

面向高三地理学习的“AI + 家长”诊断型学习项目。它不是一个单纯的题库，也不是把 ChatGPT 塞进网页，而是记录一条可复盘的学习证据链：

**作答 → 写理由 → AI 诊断候选 → 家长确认 → 同类复测 → 更新掌握状态**

## 当前版本：v0.11.0

首版刻意不接在线 API，避免在学习方法尚未验证前把项目做成昂贵的聊天框。AI 通过复制结构化提示词到 ChatGPT 完成，结果再粘贴回项目；家长是最终审核者。

已包含：

- 今日任务与学习概况；
- 单题诊断流程；
- 学生作答理由、信心等级和错因候选；
- AI 诊断提示词复制、结果粘贴；
- 家长审核、备注和“需要再看”标记；
- 主题掌握统计；
- 本地保存、JSON 导入/导出；
- 3 道原创示例题，覆盖自然地理、人文地理和区域认知。

## 本地运行

在项目目录执行：

```bash
npm test
npm start
```

然后打开 <http://localhost:4173>。

也可以直接执行：

```bash
python3 -m http.server 4173
```

## 在线访问

固定网址：<https://uau9.github.io/orange-geography-coach/>

在 iPad 或 iPhone 上使用 Safari 打开后，可以点击“分享”→“添加到主屏幕”，以后从桌面图标进入。网页和匿名题目通过 GitHub Pages 发布；学生作答、家长审核和掌握记录仍保存在当前浏览器的 LocalStorage 中，不会上传到 GitHub，也不会自动同步到其他设备。

如果学生和家长使用不同设备，当前版本需要通过“导出可批注学习档案”和“导入批注档案”交接；不要发送含个人身份信息的导出文件。具体流程见 [学习档案与批注](docs/LEARNING_EXPORT.md)。

## 维护结构

- `data/`：题目、实验和学习项目清单；
- `schemas/`：数据与导出格式约束；
- `assets/features/`：按功能拆分的经典脚本模块；
- `assets/app.js`：路由、状态与各学习流程的集成层；
- `docs/ARCHITECTURE.md`：新增专题和升级数据时的维护规则。

## 一次真实使用建议

第一周不要追求每天做很多题。每天 15–25 分钟：

1. 橙子完成 1 道题，并写出为什么这样选；
2. 将诊断提示词交给 AI；
3. 家长只检查“理由是否真实、AI 诊断是否有证据、下一步是否明确”；
4. 48–72 小时后再做同类变式题；
5. 周末复盘：哪些错误是知识不会，哪些是读图/审题/推理链断裂。

### 时区专项的一次使用

1. 进入“时区实验室”，先在世界地图上选择城市或地点，必要时再用滑杆微调经度；
2. 在看结果前，写出东西位置、地方时、理论区时、日期和判断链；
3. 提交后只核对错误发生在哪一步，不把一次满分直接写成掌握；
4. 完成8道诊断题，家长确认高频 `error_tag`；
5. 48—72小时后完成“同一瞬间的三种时间”复测。

### 晨昏线专项的一次使用

1. 选择北极、南极或赤道观察视角；
2. 提交前依次判断受光半球、自转方向、昼夜变化和晨昏线名称；
3. 解锁图中运动箭头后，对照自己的文字判断链；
4. 家长确认候选错因是否能被作答证据支持；
5. 至少48小时后换观察视角和交点复测，不能用一次满分宣布掌握。

### 太阳直射点与昼夜长短专项的一次使用

1. 选择二分二至日和一个具体城市或纬度地点；
2. 先判断太阳直射纬线，再判断目标地昼夜状况；
3. 把单点结论扩展为全球由南向北的昼长变化；
4. 用“90°－目标纬度与直射纬度之差”计算正午太阳高度；
5. 提交后只核对断在哪一步，至少48小时后换日期和半球复测。

### 日出日落与太阳视运动专项的一次使用

1. 选择二分二至日和一个具体地点；
2. 先由太阳直射点判断日出与日落位于地平圈的哪一侧；
3. 再比较当地纬度与直射纬度，判断正午太阳位于正北、头顶还是正南；
4. 用“影子与太阳相反”判断正午影子，写出两条规则的区别；
5. 提交后拖动时间轴观察太阳和影子，再在至少48小时后换日期复测。

### 太阳直射点周年回归专项的一次使用

1. 选择二分二至或两个节气之间的一个周年位置；
2. 用纬度滑杆估计太阳直射纬度，不先看周年曲线；
3. 分开判断“目前在哪里”和“正在向北还是向南”；
4. 再把移动方向转化为北半球昼长和北京/悉尼正午太阳高度趋势；
5. 提交后拖动一年复盘，至少48小时后换到相反移动方向复测。

### 地球公转轨道与速度专项的一次使用

1. 选择1月、4月、7月或10月初的轨道位置和一个半球；
2. 先由太阳位于椭圆焦点判断日地距离，再用“近日点快、远日点慢”判断公转速度；
3. 根据地轴倾斜且空间指向近似不变，判断所选半球季节；
4. 用同一时刻南北半球季节相反，检验“日地距离决定四季”的说法是否成立；
5. 提交后拖动一年观察约距离、约速度和30天轨迹，至少48小时后换近日点/远日点及半球复测。

### 晨昏线综合联动专项的一次使用

1. 读取日期、UTC时刻和目标地点，经由“地方时12:00”先定位太阳直射经线；
2. 按经度差换算目标地点地方时，不使用法定区时；
3. 结合日期、纬度和昼长推出日出日落，再判断白昼区、黑夜区、晨线或昏线；
4. 独立判断南北极圈的极昼极夜范围并写出五步判断链；
5. 提交后拖动UTC时刻解释“哪些量改变、哪些量只由日期和纬度决定”，至少48小时后换日期与状态类型复测。

## 当前边界

- 数据保存在当前浏览器的 LocalStorage，不具备自动多设备同步；学习档案可用于人工迁移；
- AI 结果仍需复制粘贴，便于先验证流程，也避免把密钥放入前端；
- 示例题不是完整高考地理课程，正式内容必须经过家长或教师审核；
- 不能依据一次答错就断言橙子“掌握不足”，系统只记录候选诊断。
- 真实试卷图片与个人信息不写入仓库；录入数据只保留匿名分数、评分点摘要和诊断证据。
