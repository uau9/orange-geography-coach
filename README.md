# 橙子地理教练

面向高三地理学习的“AI + 家长”诊断型学习项目。它不是一个单纯的题库，也不是把 ChatGPT 塞进网页，而是记录一条可复盘的学习证据链：

**作答 → 可选记录理由 → AI 诊断候选 → 家长确认 → 同类复测 → 更新掌握状态**

## 本地运行

在项目目录执行：

```bash
npm test
npm start
```

然后打开 <http://localhost:4173>。

也可以直接执行：

```bash
python3 -m http.server 4173
```

## 一次真实使用建议

第一周不要追求每天做很多题。每天 15–25 分钟：

1. 橙子完成 1 道题；选择理由可写可不写；
2. 将诊断提示词交给 AI；
3. 家长在有理由时检查其是否真实；无理由时只把 AI 结论视为证据不足的候选；
4. 48–72 小时后再做同类变式题；
5. 周末复盘：哪些错误是知识不会，哪些是读图/审题/推理链断裂。

### 时区专项的一次使用

1. 进入“时区实验室”，先在世界地图上选择城市或地点，必要时再用滑杆微调经度；
2. 对照实时联动图，完成东西位置、地方时、理论区时和日期预测；判断链选填；
3. 提交后只核对错误发生在哪一步，不把一次满分直接写成掌握；
4. 完成8道诊断题，家长确认高频 `error_tag`；
5. 48—72小时后完成“同一瞬间的三种时间”复测。

### 晨昏线专项的一次使用

1. 选择北极、南极或赤道观察视角；
2. 对照默认可见的图示，依次判断受光半球、自转方向、昼夜变化和晨昏线名称；
3. 提交后核对具体错误步骤；文字判断链可选填；
4. 家长确认候选错因是否能被作答证据支持；
5. 至少48小时后换观察视角和交点复测，不能用一次满分宣布掌握。

### 太阳直射点与昼夜长短专项的一次使用

1. 选择二分二至日和一个具体城市或纬度地点；
2. 先判断太阳直射纬线，再判断目标地昼夜状况；
3. 把单点结论扩展为全球由南向北的昼长变化；
4. 用“90°－目标纬度与直射纬度之差”计算正午太阳高度；
5. 提交后只核对断在哪一步，至少48小时后换日期和半球复测。

### 日出日落与太阳视运动专项的一次使用

1. 选择二分二至日和一个具体地点；
2. 先由太阳直射点判断日出与日落位于地平圈的哪一侧；
3. 再比较当地纬度与直射纬度，判断正午太阳位于正北、头顶还是正南；
4. 用“影子与太阳相反”判断正午影子，写出两条规则的区别；
5. 提交后拖动时间轴观察太阳和影子，再在至少48小时后换日期复测。

### 太阳直射点周年回归专项的一次使用

1. 选择二分二至或两个节气之间的一个周年位置；
2. 用纬度滑杆估计太阳直射纬度，不先看周年曲线；
3. 分开判断“目前在哪里”和“正在向北还是向南”；
4. 再把移动方向转化为北半球昼长和北京/悉尼正午太阳高度趋势；
5. 提交后拖动一年复盘，至少48小时后换到相反移动方向复测。

### 地球公转轨道与速度专项的一次使用

1. 选择1月、4月、7月或10月初的轨道位置和一个半球；
2. 先由太阳位于椭圆焦点判断日地距离，再用“近日点快、远日点慢”判断公转速度；
3. 根据地轴倾斜且空间指向近似不变，判断所选半球季节；
4. 用同一时刻南北半球季节相反，检验“日地距离决定四季”的说法是否成立；
5. 提交后拖动一年观察约距离、约速度和30天轨迹，至少48小时后换近日点/远日点及半球复测。

### 晨昏线综合联动专项的一次使用

1. 读取日期、UTC时刻和目标地点，经由“地方时12:00”先定位太阳直射经线；
2. 按经度差换算目标地点地方时，不使用法定区时；
3. 结合日期、纬度和昼长推出日出日落，再判断白昼区、黑夜区、晨线或昏线；
4. 独立判断南北极圈的极昼极夜范围；五步判断链可选填；
5. 提交后拖动UTC时刻解释“哪些量改变、哪些量只由日期和纬度决定”，至少48小时后换日期与状态类型复测。

### 地球自转速度专项的一次使用

1. 读取目标地点纬度和观察时长，先由24小时转360°判断角速度；
2. 比较该纬线圈与赤道周长，判断线速度关系；
3. 用赤道线速度约1670 km/h乘 `cos纬度` 估算当地线速度；
4. 分别用 `15°/h×时间` 和 `线速度×时间` 求转角与纬线弧长；
5. 提交后拖动24小时解释“为什么转角相同而路程不同”，至少48小时后跨低纬与高纬复测。

### 全球日期范围专项的一次使用

1. 读取UTC时刻，用“UTC每增加1小时，0时经线向西移动15°”定位地方时0时经线；
2. 从0时经线向东到180°经线判为较新日期，并按经度跨度计算占比；
3. 用两侧占比合计100%检查较旧日期范围；
4. 分开判断全球日期数量与跨180°经线后的日期加减；
5. 提交后拖动UTC一天，至少48小时后换到“全球一个日期/两个日期”的另一类情境复测。

### 黄赤交角与五带专项的一次使用

1. 读取目标黄赤交角 ε，先写出回归线纬度等于 ε；
2. 用 `90°−ε` 求极圈纬度，区分极昼边界与极昼区域；
3. 用 `2ε` 求热带总宽，用 `90°−2ε` 求每个温带的纬度宽度；
4. 比较当前23.5°，判断交角增大时热带、寒带变宽而温带变窄；
5. 提交后拖动0°—45°反事实模型，至少48小时后换到交角变化方向相反的情境复测。

### 天体系统尺度专项的一次使用

1. 先用“谁围绕谁运动”确定地月系与太阳系，再把太阳视为银河系中的一颗恒星；
2. 写出地月系→太阳系→银河系→可观测宇宙（教材常称总星系层级）的包含链；
3. 给地月距离匹配千米、给日地距离匹配AU、给银河系尺度匹配光年；
4. 判断太阳系位于银河系猎户臂附近，不在银心，也不在银河系之外；
5. 提交后拖动四级缩放尺，至少48小时后在内层与外层系统之间换情境复测。

### 太阳活动专项的一次使用

1. 先读三条原始观测，识别它描述的是活动指标、耀斑、高能粒子、CME还是高速太阳风；
2. 分开匹配电磁辐射、高能带电粒子和磁化等离子体，不能因现象伴随发生就共用到达时间；
3. 用约8分钟、分钟至小时、数十小时至数日等时标检查地球响应的先后；
4. 判断无线电、航天辐射、地磁暴、极光、导航或电网影响时，保留“可能”和方向、磁场条件；
5. 提交后拖动证据尺复盘，家长确认候选错因；至少48小时后跨电磁辐射与CME情境复测。

### 月相专项的一次使用

1. 从北极上空俯视图确认太阳方向，再读取月球相对地球的轨道位置；
2. 先判断月相和从地球看到的亮面比例，再判断处于渐盈、渐亏还是朔望交界；
3. 以太阳约12时过中天为参照，每相约相差3小时，推导月升、中天和月落近似时刻；
4. 用连续变化和可见时段区分亮面比例相同的盈凸/亏凸、蛾眉月/残月；
5. 提交后拖动完整八相月轨，家长追问“为什么普通月相不是地影”；至少48小时后换到盈亏相反情境复测。

### 日月食专项的一次使用

1. 先由新月或满月判断日—月—地、日—地—月次序，再检查是否接近轨道交点；
2. 区分本影、半影和伪本影落在地表，或月球进入地球本影/半影；
3. 由影区判断日全食、日环食、日偏食与三类月食；
4. 把“发生什么食”与“观察地能看见什么食相”分开，比较日食局地影带与月食夜半球范围；
5. 提交后拖动八种几何情境；至少48小时后跨日食/月食复测并由家长确认。

### 潮汐专项的一次使用

1. 先由月相还原太阳、地球、月球的方向关系；
2. 判断日月引潮作用是近似同轴叠加，还是方向近似垂直而部分抵消；
3. 再判断大潮、小潮或过渡阶段，以及潮差总体变大或变小；
4. 区分朔望月中的潮差变化和一个太阴日内常见的高潮低潮循环；
5. 最后说明模型只能给出总体规律，某港口的准确潮时潮高必须查当地资料；至少48小时后跨大潮/小潮复测并由家长确认。

## 当前边界

- 数据保存在当前浏览器的 LocalStorage，不具备自动多设备同步；学习档案可用于人工迁移；
- AI 结果仍需复制粘贴，便于先验证流程，也避免把密钥放入前端；
- 示例题不是完整高考地理课程，正式内容必须经过家长或教师审核；
- 不能依据一次答错就断言橙子“掌握不足”，系统只记录候选诊断。
- 真实试卷图片与个人信息不写入仓库；录入数据只保留匿名分数、评分点摘要和诊断证据。
